# テキスト出力

会話内で直接テキストとして報告する。

## 構成

### サマリー

3分で説明できる「結果と次のアクション」をまとめる。意思決定に必要な情報だけを抽出し、全員に同じ内容を正確に伝える。

| セクション | 内容 |
|---|---|
| 3大ポイント | 今期の結果から最も重要な3つの発見を箇条書きで示す |
| ゴールとKPI | 主要KPI（セッション数・アクティブユーザー数・チャネル構成など）の実績値と前期間比を並べ、傾向を示す |
| やるべきこと | 分析結果から導かれる具体的なアクション項目を優先度順に示す |

### 数値×施策レポート

数値だけでは施策の効果判断ができない。数値と施策情報を並べ、何が数値を動かしたかを読み取れるようにする。

| 要素 | 内容 |
|---|---|
| 数値 | テーブルによる指標推移（セッション数、チャネル別内訳、ランディングページ別内訳など） |
| 施策 | 広告出稿・SEO施策・SNS投稿・メルマガ配信などKPIごとの施策一覧（実施済み・予定） |

施策と数値を並べることで、施策が数値に与えた影響を把握でき、次の打ち手の判断材料になる。

### 改善施策の提案

施策提案では「精度ではなくロジック」を重視する。過去の実績データを根拠に効果を換算し、セッション数・売上インパクトを数値で示す。

| ルール | 内容 |
|---|---|
| 根拠を示す | 過去実績から効果を算出する（例:「オーガニック検索からの流入が月1,000セッション増えると、現状CVRから受注件数◯件増が見込める」） |
| 選択肢を出す | 施策案を複数提示し、それぞれの期待効果と優先度を示す |
| 曖昧にしない | 「やってみないとわかりません」は避け、ロジックで説明する |
