# クロスチャネル統合分析

GA4の流入データ（このスキル）と、Makeshopの売上・注文データ（`makeshop/shop-analytics` スキル）を組み合わせて統合分析するための考え方をまとめる。単独では見えない「流入対効果」「チャネル別の売上貢献度」を可視化するときに使う。

## 対象期間の揃え方

両スキルとも**同じ対象期間・同じ比較期間**を指定する。片方だけ期間がずれると、セッション数と受注件数の対応関係が崩れ、CVRの算出が意味をなさなくなる。

- GA4側: `scripts/ga4_query.py --start-date --end-date --compare-start-date --compare-end-date`
- Makeshop側: shop-analyticsスキルの注文取得ツールに同じ期間を指定する

ヒアリング段階（SKILL.mdの1-4「対象期間」）で期間を確定させたら、そのまま両スキルのデータ取得ステップに渡す。

## 流入対効果（CVR）の算出

### 定義
セッション数に対して、どれだけ受注につながったかを示す指標。

#### 計算方法
1. GA4から対象期間の合計セッション数を取得する（`references/metrics-dimensions-reference.md` の「基本サマリー」、`--dimensions ""`）
2. Makeshopのshop-analyticsスキル（`analysis-reference-basic.md`）から対象期間の受注件数を取得する
3. CVR = 受注件数 ÷ セッション数 × 100

#### 用途
セッション数が伸びていても受注件数が伴わない場合は、集客の「量」は足りているが「質」やサイト内導線・決済フローに問題がある可能性が高い。逆にセッション数が減っても受注件数が維持されている場合は、質の高い流入に絞れていると判断できる。

## チャネル別の売上効果測定

### 定義
GA4のチャネル別セッション数と、Makeshopの新規/既存顧客データを突き合わせ、どのチャネルが売上に貢献しているかを評価する。

#### 計算方法
1. GA4から `sessionDefaultChannelGroup` 別セッション数を取得する（`references/metrics-dimensions-reference.md` の「チャネルグループ別セッション数」）
2. Makeshopのshop-analyticsスキル（`analysis-reference-new-existing.md` または `analysis-reference-basic.md`）から対象期間の新規/既存購入会員数・売上を取得する
3. チャネルごとのセッション構成比と、新規売上比率・既存売上比率を並べて考察する（GA4はチャネル単位でユーザーを紐付けできないため、直接の1:1対応ではなく「構成比の突き合わせ」による相関的な考察になる点に注意する）

#### 用途
Organic SearchやPaid Searchの構成比が高い時期に新規売上比率が上がっていれば新規獲得チャネルとして機能している、というように、チャネル構成の変化と売上構成の変化を時系列で並べて評価する。広告予算配分やSEO/SNS施策の優先順位付けに使う。

## 検索面での改善提案が必要な場合

検索クエリ・掲載順位など検索エンジン経由の詳細データが必要な場合は、`google-search-console` スキル（同じ型のスキル、別途作成）の検索クエリ・掲載順位データも合わせて読む。GA4はどのページに流入したかまでは分かるが、どんな検索語句で見つかったかはSearch Console側のデータが必要になる。

## ダッシュボードの統合方法

レポートは `references/report-reference-html.md` のスタイル（Makeshop shop-analyticsスキルと共通のカラーパレット・レイアウト原則）に従い、Makeshop側のKPIカード（売上金額・受注件数・客単価）とGA4側のKPIカード（セッション数・アクティブユーザー数・CVR）を同じ上段グリッドに並べて1つのダッシュボードにまとめる。

- 上段: 売上KPI（Makeshop）+ 流入KPI（GA4）+ CVR（統合算出値）を横並びのKPIカードで並べる
- 中段: 売上推移グラフとセッション推移グラフを左右または上下に並べ、同じ時間軸で比較できるようにする
- 下段: チャネル別セッション構成と新規/既存売上構成を並べ、チャネル別の貢献度を考察する

すべてのグラフ・カードで `references/report-reference-html.md` のカラーパレット（`#264AF4` / `#0031D8` / `#FA0000` / `#E8F1FE` / `#FDEEEE` / `#1A1A1A` / `#626264` / `#F8F8FB` / `#D8D8DB`）を統一して使う。
